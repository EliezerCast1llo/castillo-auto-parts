# Design Agent Brief - Canva / UI Direction

## Objetivo

Crear una primera propuesta visual en Canva para validar direccion de marca, estilo UI y jerarquia de pantallas antes de seguir profundizando frontend.

El resultado no debe ser una landing decorativa. Debe mostrar una experiencia usable de e-commerce de repuestos.

## Contexto

- Producto: e-commerce de repuestos automotrices en El Salvador.
- Zona inicial: San Salvador y Santa Tecla.
- Codename actual: Castillo Auto Parts.
- Marca final: pendiente por posible conflicto comercial.
- Idioma principal: espanol.
- Idioma secundario: ingles.
- Referencia deseada: retail moderno tipo Siman.
- Evitar: estilo viejo/torpe tipo RockAuto.

## Direccion Visual

Paleta provisional:

- Azul profundo: `#12324A`.
- Verde stock/compatibilidad: `#19A974`.
- Amarillo acento: `#F2B705`.
- Gris claro fondo: `#F5F7F8`.
- Carbon texto: `#1E252B`.
- Blanco: `#FFFFFF`.

Tipografia sugerida:

- Inter o Manrope.
- Alta legibilidad en mobile.
- Numeros, SKU y precios deben ser faciles de escanear.

Estilo:

- limpio;
- confiable;
- moderno;
- con jerarquia fuerte;
- botones claros;
- fotografia/placeholder de producto consistente;
- iconografia simple.

## Canva Design Recomendado

Crear una presentacion horizontal 16:9 con estas secciones:

1. Portada:
   - "Castillo Auto Parts - UI Direction"
   - Nota: codename provisional.

2. Moodboard:
   - retail moderno;
   - e-commerce automotriz;
   - piezas/productos claros;
   - no taller oscuro, no catalogo viejo.
   - contexto urbano salvadoreno/centroamericano;
   - taller limpio;
   - mapas, pines, delivery y pickup.

3. Paleta y tipografia:
   - colores;
   - uso de colores por estado;
   - ejemplos de botones.
   - badges: Disponible, En camino, Retiro en tienda, Entrega hoy, Oferta, OEM, Compatible.

4. Home:
   - header con buscador;
   - selector de vehiculo;
   - categorias;
   - productos destacados;
   - confianza: compatibilidad, retiro, envio local.
   - copy sugerido: "Busca por placa, modelo, VIN, categoria o numero de parte. Entregamos en El Salvador."

5. Catalogo:
   - filtros desktop;
   - filtros mobile;
   - tarjetas de producto;
   - badges de stock/preorder.
   - ordenamiento por relevancia, precio menor/mayor y entrega mas rapida.

6. Detalle de producto:
   - galeria;
   - precio;
   - compatibilidad;
   - selector cantidad;
   - agregar al carrito;
   - validar con asesor.

7. Checkout mapa/pin:
   - retiro en bodega;
   - envio local;
   - mapa/pin;
   - notas de entrega;
   - resumen de orden.
   - estados: Ubicacion confirmada, Zona con entrega disponible, Necesitamos confirmar cobertura.

8. Admin ordenes:
   - tabla/listado;
   - filtros por estado;
   - detalle de orden;
   - estado pago/DTE.
   - estados operativos: Nueva, Confirmando, Pagada, Preparando, En ruta, Entregada, Cancelada.

9. Mobile:
   - home mobile;
   - catalogo mobile;
   - detalle mobile;
   - checkout mobile.

10. QA visual:
   - checklist de legibilidad;
   - contraste;
   - no solapamientos;
   - CTA visible;
   - compatibilidad visible.

## Copy Inicial

- "Encuentra el repuesto correcto para tu vehiculo."
- "El repuesto correcto, mas facil de encontrar."
- "Busca por marca, modelo, ano o numero de parte."
- "Busca por vehiculo, categoria o numero de parte."
- "Compatible con tu vehiculo."
- "Disponible para retiro o envio local."
- "No estas seguro? Validamos contigo."
- "Precio con IVA incluido."
- "Confirma compatibilidad antes de pagar."
- "Atencion por WhatsApp para validar tu repuesto."

## Criterios De Aceptacion Visual

- El usuario entiende en menos de 5 segundos que puede buscar por vehiculo.
- Stock y compatibilidad son visibles antes de comprar.
- El catalogo no parece tabla vieja.
- Mobile permite comprar con una mano.
- El diseno no depende de fondos oscuros o imagenes decorativas.
- Los productos tienen jerarquia clara: nombre, marca, parte, compatibilidad, precio, stock, accion.
- El admin se ve operativo, no como landing.
