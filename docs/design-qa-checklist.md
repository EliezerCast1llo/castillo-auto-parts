# Design QA Checklist

## Objetivo

Checklist para revisar propuestas visuales de Canva/Figma/v0 antes de convertirlas en frontend.

## Marca Y Claridad

- [ ] El codename se marca como provisional.
- [ ] La pantalla comunica e-commerce de repuestos, no taller o landing generica.
- [ ] La propuesta se siente moderna y confiable.
- [ ] La propuesta evita apariencia de catalogo viejo.
- [ ] La UI esta en espanol por defecto.
- [ ] La opcion de ingles no mezcla idiomas en la misma pantalla.

## Home

- [ ] Buscador principal visible.
- [ ] Selector por vehiculo visible.
- [ ] Categorias iniciales claras.
- [ ] Productos destacados visibles.
- [ ] Confianza visible: compatibilidad, retiro, envio, soporte.
- [ ] No hay hero decorativo que tape la funcionalidad.

## Catalogo

- [ ] Filtros son faciles de encontrar.
- [ ] Tarjetas tienen imagen, nombre, marca, parte, compatibilidad, precio y stock.
- [ ] Stock/preorder se distinguen claramente.
- [ ] CTA principal es consistente.
- [ ] No hay saturacion visual.
- [ ] Mobile tiene filtros accesibles sin tapar el listado.

## Detalle Producto

- [ ] Compatibilidad es protagonista.
- [ ] Precio y stock se ven rapido.
- [ ] CTA "Agregar al carrito" es claro.
- [ ] CTA "Validar con asesor" es secundario.
- [ ] Detalles tecnicos son legibles.
- [ ] Galeria/imagen mantiene proporcion.

## Checkout

- [ ] Retiro en bodega y envio local se entienden.
- [ ] Mapa/pin se ve editable.
- [ ] Notas de entrega estan presentes.
- [ ] Resumen de orden es claro.
- [ ] Total y envio no se pierden en mobile.

## Admin

- [ ] Vista parece herramienta operativa.
- [ ] Ordenes por estado son claras.
- [ ] Pago, envio y DTE tienen estado visible.
- [ ] Tabla/listado es escaneable.
- [ ] No usa estilo de landing para tareas administrativas.

## Responsive

- [ ] Mobile 360px no corta textos.
- [ ] Mobile 390px permite completar acciones principales.
- [ ] Tablet mantiene jerarquia.
- [ ] Desktop no deja contenido demasiado disperso.
- [ ] Botones tienen tamano tactil suficiente.

## Accesibilidad Basica

- [ ] Contraste legible.
- [ ] No se usa solo color para estados.
- [ ] Estados tienen texto o icono.
- [ ] Tipografia es legible.
- [ ] CTAs tienen jerarquia clara.

## Resultado QA

- [ ] Aprobado para implementar.
- [ ] Aprobado con cambios.
- [ ] Rechazado.
